# Changelog: awna-intake-pg

This package is versioned on its own. Its releases are tagged `awna-intake-pg-vX.Y.Z` (for example `awna-intake-pg-v0.1.0`).

## 0.1.0 - 2026-11-25

- A transactional Postgres store for intake items, a schema for the host's migration, and a command line for local database access and file export.
